# Game Manifest Index

**按游戏与版本浏览官方资源清单，查找历史安装包、补丁和下载链接。**

Game Manifest Index 是一个游戏资源索引与归档项目，收录 Android 安装包以及 PC 客户端的完整包、更新补丁、语音资源和分块清单。它将分散在游戏官网、启动器与 CDN 中的资源元数据整理为可浏览、可搜索、可比较的版本记录。

项目提供资源链接与来源信息，**不托管游戏安装包**。

## 主要功能

### 版本归档

按游戏、平台和版本查看已收录资源，包括文件名、大小、校验值、下载地址与最近探活时间。历史版本与当前版本使用统一的浏览方式，便于查找特定版本的安装包和资源记录。

### PC 资源清单

查看已接入游戏的完整包、补丁、语音包及 Chunk 信息；支持文件搜索、目录浏览和版本差异比较。不同游戏的官方资源格式不同，可用视图以对应模块实际支持的能力为准。

### 下载链接探活

检查已收录链接的可用性，展示探活结果和判定原因；支持手动探活与定时轮次。定时轮次先从官方来源发现新版本，再检查新发现或上次探活可用的官方与历史链接，跳过已确认失效或未判定的链接，并保留最近的检查记录。

| 状态 | 含义 |
| --- | --- |
| 可用 | 本次探活取得了有效的可下载证据 |
| 失效 | 本次探活取得了资源不可下载的明确证据 |
| 未知 | 现有证据不足以确认资源状态，例如访问被拒绝、返回验证页 |
| 探活异常 | 请求或处理过程中发生错误，未完成有效判定 |

探活结果反映检查时的状态，不保证后续下载始终成功。仍在定时轮换范围内的可用证据过期后会标记为陈旧；普通 HTTP 403 不会被直接当作文件已删除。

### 来源查询

展示资源的来源与归档信息，区分官方发现结果和历史导入记录。查找链接时可以同时核对文件、版本与来源，避免把不同渠道的资源混在一起。

### 资源管理

管理端支持游戏与模块目录维护、版本和资源编辑、采集任务、批量探活、定时计划及执行日志。管理操作受 Token 鉴权保护。

## 数据来源

日常发现、同步和自动任务使用游戏厂商的官方网站、API、启动器及 CDN 元数据。第三方资料仅用于明确指定的历史导入或回填流程，并保留实际来源，不作为默认发现来源或后备源。

这是一个非官方资源索引项目。游戏名称、图标及相关资源归各自权利人所有。

## 技术构成

- **前端**：Vue 3、TypeScript、Vite。
- **后端**：Python、FastAPI。
- **定时探活**：APScheduler。
- **数据存储**：统一 JSON 记录、资源索引与清单文件，采集和探活适配器按平台及厂商组织。

## 当前边界

- 不提供游戏文件托管，也不保证官方链接长期有效。
- 各游戏的采集、清单解析和版本比较能力，以已接入模块为准。
- 已有历史记录不等于已接入自动发现，也不保证归档完整。
- 已实现定时轮次中的官方新版本发现与探活；每日采集计划的独立定时执行、数据保留与自动清理策略尚未接通。
